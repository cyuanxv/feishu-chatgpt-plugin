# 完整工具运行与验收

## 开关与授权

`FEISHU_DOCX_ENABLED=true` 暴露通用读工具；`FEISHU_WRITE_ENABLED=true` 暴露写入预览和状态工具。写开关默认关闭。开关不会向飞书自动新增授权。连接管理页按应用已开通的能力请求当前功能需要的权限，API 实际授权、资源可见范围与用户身份共同决定能否执行。

禁用写开关并重新部署可暂停预览与执行。已经写入飞书的数据不随回滚删除。保留 D1 新表；旧 Worker 可忽略它们。密钥与 token 不进源码、日志或验收记录；只通过 Sites secret 配置。

## 验证与告警边界

`npm ci && npm test`、`npm run typecheck`、`npm run check:source`、`npm run check:package`；原生运行时在 runtime-check 安装依赖后执行 `npm run check:workerd`。测试覆盖真实 workerd 和 SQLite/D1 幂等，但注入的 Feishu 返回值都是合成数据。

已有 OAuth 元数据诊断只记录布尔检查和版本；不能把日志成功当成业务成功。写入回执加密保存，按用户与站点隔离。没有外部监控/报警服务，不宣称已经有人值守。对于执行中崩溃、未知响应和部分完成，回执是排查入口，禁止自动重放。

当前回执没有自动清理策略；管理员应按实际留存需求配置后再接入删除任务。未完成意图 15 分钟后不可执行，但不自动从数据库删除。不能删除幂等记录后再重放旧请求。

## 自部署与发行

此目录是 Sites Workers + D1 实现，与仓根历史 Node/Postgres 实验分开。使用本目录 README 的 Sites 配置，保持 owner-private；创建新环境需要独立 Feishu callback 与加密密钥。不能把现有站点密钥复制到公开示例。

CI 对快照运行离线回归；干净新租户部署、外部模型评测、独立安全审查和公开目录审核仍需独立证据。该版本是现有私有站点的功能候选，不代表公共发行验收。

## 实际数据验收矩阵

- 已有范围沿用上一版日程、文档、知识库、电子表格、多维表格和任务读取证据。
- 新增联系人、群聊/消息/串、评论、忙闲、会议室逐个调用验证授权与可见性。

- 任务清单按用户要求等真实数据后补验收。
