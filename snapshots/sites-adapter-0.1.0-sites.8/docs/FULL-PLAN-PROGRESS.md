## 已固定的边界

- 所有写工具只生成预览；MCP 不接受 `confirmed` 或其他自行确认参数。用户必须在受保护网页上确认。
- 写入意图绑定本站用户、应用、授权代际、完整参数和请求 ID；敏感内容与回执加密保存。
- 一个意图只争抢一次执行权。并发确认、重复确认、断线重试不重新提交；请求结果未知时保留核查状态。
- 执行多个步骤时逐次核对授权。创建日程成功、添加会议室失败会保留日程 ID，并报告部分完成，不自动删除。
- 待审批与待用户确认是两个数据库状态；待审批不能再次提交。可通过回执刷新重新读取会议室 RSVP。
- DOCX 写入支持纯文本创建、追加及带版本号的指定块替换；不承诺任意富文本编辑、文件下载或附件写入。
- Base 筛选明确支持文本、数字、单选字段的等于/包含/大于/小于适用组合；不 silently drop 不支持条件。
- 查询仍有请求预算：20 项每页、schema 最多 400 字段、sheet 每次 2000 单元格、跨页游标有时效。统一搜索不声称全局相关性排序。
