## 已确认的增量能力

- 多应用：同一账户按实际权限自动选择；游标、引用和写入预览绑定连接，不混用跨应用 Open ID。
- 通用只读：知识库、电子表格、多维表格、任务已实测；tasklist_tasks 等真实清单再补验。
- 会议室：预订→资源确认→取消→同一时段可用回读通过；需审批房间的实际审批流程未验收。
- cancel_event：无参会人测试日程再次确认取消；循环日程明确不支持。
- 日程 PDF 附件：三份真实附件云端下载、页数解析、加密保存与回读成功。最多 512 KiB，24 小时逻辑期限，过期实体在后续下载清理；不含 OCR 或面试分析。
